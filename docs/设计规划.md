# SteamMonitor 设计规划（0.8 – 1.0）

本文在 [项目计划书](项目计划书.md) 和 [活动页设计提案](活动页设计提案.md) 的基础上，盘点 0.7.4 的实际状态，给出到 1.0 的功能范围、界面方案和里程碑。代码结构见 [架构说明](架构说明.md)。

## 一、产品定位

SteamMonitor 是一个本地运行的 Windows 工具，回答三个问题：

1. **现在**谁在线、谁在玩什么、能不能凑一局？
2. **刚才**某段时间里大家各自做了什么，记录是怎么来的？
3. **最近**一周或一个月，谁玩了什么、和谁一起玩、常在什么时间段活跃？

设计原则沿用计划书，并在界面上明确落实：

| 原则 | 落在界面上的要求 |
| --- | --- |
| 只呈现可见数据 | 「显示离线」「状态未知」「采集缺口」三者在颜色、形状和文字上都能区分。统计结果标注「估算」和采集覆盖率。 |
| 证据可追溯 | 每个色带、菱形和统计数字都能点开，看到起止采样、对比样本和缺口。 |
| 授权在前 | 开始记录、时长采样、好友发现都要求显式勾选确认，确认时间和文字留档可查。 |
| 本地优先 | 数据只写入本机。界面常驻「本机存储」提示，数据页可查看库大小、记录范围并一键导出或清除。 |
| 安静 | 通知默认关闭，建立基线后才提醒，免打扰与冷却统一管理。 |

## 二、现状盘点（0.7.4）

### 已完成

| 模块 | 能力 |
| --- | --- |
| 数据源 | 演示数据；Steam Web API Key（系统凭据加密）；60 秒批量轮询，限流退避；休眠、暂停、断网记为缺口 |
| 好友名单 | SteamID64 或资料链接添加；导入公开好友名单；好友发现（每 30 分钟检查新增好友）；备注、置顶、暂停、移除 |
| 好友页 | 搜索（Ctrl+K）、状态筛选、按游戏分组和置顶游戏；详情显示当前状态、最近 8 条事件、资料与商店链接 |
| 活动页 | 多好友泳道；概览拖选；缩放、平移、键盘操作；预设与自定义日期（≤31 天）；游戏筛选；事件列表与泳道联动；CSV 导出；缺口阈值；同期缺口批量删除 |
| 好友时间轴 | 状态与游戏色带、时长副行、公开时长增长菱形；公开时长对比实验（手动或自动采样，需授权） |
| 回顾 | 7 天、30 天游戏时长与共同游玩时段；按日查看游戏时段并跳转到时间轴和活动页 |
| 通知 | 上线、开始玩、凑够人数；指定一位好友或一个游戏关键字；免打扰时段与冷却 |
| 数据与系统 | 保留天数、备份与恢复、清除历史、开机启动、托盘常驻 |
| 更新 | GitHub 发布检查；界面包热更新（试运行 10 秒，失败自动回滚）；完整版本跳转下载页 |

### 需要解决的问题

| 类别 | 问题 |
| --- | --- |
| 上手 | 首次启动直接进入演示模式，「连接 Steam 数据」只是跳到设置页。用户要自己找到 Key 输入框、再回到好友页添加账号，缺少连贯的引导。 |
| 好友页 | 打开时间轴的入口有两个（名单标题栏和详情标题栏）。计划书原定详情显示「当日时间线」，现在只有 8 条文字事件。开黑视图依赖「按游戏分组」开关，平时看不到谁在一起玩。 |
| 活动页 | 筛选、概览、泳道、事件列表纵向堆叠，在默认 810 px 高的窗口里泳道只露出约 5 行。事件列表要切换才能看到。 |
| 回顾页 | 只有列表，没有提案中提到的活跃热力图，也看不出「和谁一起玩得最多」。 |
| 通知 | 只能指定一位好友和一个关键字，无法同时关注多位好友或多款游戏；发出过的通知没有记录。 |
| 设置页 | 六个面板双列排布，靠顶部跳转按钮定位，项目增加后会越来越长。时长对比实验入口埋在时间轴页底部。 |
| 数据与隐私 | 授权确认只在勾选时存在，事后无法查看何时、对谁做过确认。没有自动备份。 |
| 外观 | 只有深色主题；界面文字写在组件里，无法切换语言。（0.8 已按「颜色只属于数据」重做视觉语言并建立令牌，见 5.1。） |
| 工程 | 数据库结构升级靠「列不存在就 ALTER」；界面没有自动化冒烟测试；快照每次变化整表推送。 |

## 三、功能规划

优先级：**P0** 为 0.8 必做，**P1** 为 0.9 – 1.0，**P2** 视验证结果决定。

### 3.1 首次使用引导（P0）

首次启动或在演示模式点「连接 Steam 数据」时打开三步引导，任何一步都可以退出回到演示。

| 步骤 | 内容 | 完成条件 |
| --- | --- | --- |
| 1 数据源 | 说明演示数据与 Steam 数据的差别、数据只存本机 | 选择「连接 Steam」 |
| 2 API Key | 输入框、申请页链接、粘贴后即时格式校验，先试调一次 `GetPlayerSummaries`，通过后才加密保存，显示成功或具体错误 | Key 已加密保存且验证通过 |
| 3 第一批记录对象 | 先添加自己的账号；可选导入公开好友名单并勾选；同页勾选授权确认；可选开启好友发现 | 至少添加 1 个账号 |

演示模式下页面顶部显示一条细横幅：「正在查看示例数据 · 连接 Steam 数据」，关闭后本次运行不再显示。

### 3.2 好友页：开黑面板与详情（P1）

- **开黑面板**：名单上方一行横向卡片，每款正在玩的游戏一张。卡片含游戏图标、中文名、头像堆叠、人数和最早开始时间。置顶游戏在前，人数达到凑人门槛时卡片描边高亮。点卡片等于按该游戏筛选名单，再点取消。无人游戏时面板收起成一行「暂无好友在游戏中」。
- **好友详情**：顶部保留头像、状态和链接；中部新增「今日」迷你时间轴（0–24 点单行色带，复用时间轴色带组件），下方显示今日游戏时长合计；底部保留最近事件。详情标题栏的「横向时间轴」成为唯一入口，名单标题栏的重复按钮移除。
- **名单行**：在游戏状态后追加「已玩 1 小时 12 分」（本次会话观测时长），离线行显示「3 小时前在线」。
- **批量操作**（P2）：多选后批量暂停、置顶、移除。

### 3.3 活动页（P1）

在提案第二步的基础上调整版面：

- 预设范围、好友、游戏、事件类型合并为一行工具栏；窄窗口折叠为「筛选」按钮。
- 概览和时间刻度吸顶，泳道区域独立滚动，宽窗口可同时看到 10 行以上。
- 事件列表改为右侧面板（≥1200 px）或底部抽屉（<1200 px），与选中项联动，默认展开。
- 泳道排序：置顶优先 → 范围内有游戏记录 → 名称；开关「只显示有活动的好友」。
- 相邻菱形和窄色带合并为带数量的聚合标记，点开后逐条展示。
- CSV 导出增加「时长增长」独立文件选项，保留发现时间和对比区间。

### 3.4 回顾页（P1）

| 模块 | 设计 |
| --- | --- |
| 活跃热力图 | 7 行（星期）× 24 列（小时）。格子颜色为该时段出现过游戏记录的好友平均人数，悬停显示人数与主要游戏，点格子跳到活动页对应时段。 |
| 游戏排行 | 横向条形图，条长为观测时长，条内标注「共同 x 小时」。点游戏查看参与好友。 |
| 搭档排行 | 两两统计同一游戏的重叠时长，列出前 10 对，用于约下一次开黑。 |
| 周报卡片 | 本周与上周对比：游戏时长、活跃好友数、共同游玩时长、采集覆盖率。 |
| 按日 | 保留现有按日时段列表和跳转。 |

所有统计都显示「估算 · 覆盖率 x%」，覆盖率低于 80% 时用琥珀色提示。

### 3.5 通知规则 2.0（P1）

- 规则列表取代单一表单。每条规则：触发（上线 / 开始玩 / 结束游戏 / 凑够人数）+ 对象（全部或多选好友）+ 游戏（不限或多选，支持中文名和 App ID）+ 启用开关。
- 全局设置：免打扰时段、重复提醒冷却、启动和重连后的基线说明。
- 「最近通知」列表保存本机最近 50 条，点击可跳到对应时间轴。
- 保留「发送测试通知」。

### 3.6 采集健康（P1）

侧栏底部的采集状态弹窗扩展为：

- 近 24 小时采样成功率条（每格 15 分钟，绿色正常、琥珀部分、红色失败、斜纹暂停或休眠）；
- 最近 5 条错误及时间；限流时显示恢复倒计时；
- 单个好友不可见时在名单行标注，弹窗汇总「x 位好友未返回数据」。

### 3.7 数据与隐私（P0 / P1）

- **P0 授权记录**：添加好友、开启时长采样、开启好友发现时，把时间和确认文字写入本地授权表。好友详情「授权」区显示记录，可撤回（撤回即暂停并可选清除历史）；撤回后恢复记录或再次采样需重新确认。好友发现针对自己的账号，记录显示在设置页的好友发现面板。0.8 之前添加的好友没有记录，不补写。
- **P1 数据概览**：数据库大小、好友数、事件数、最早记录时间、各好友占用。
- **P1 自动备份**：可选每周备份到指定目录，保留最近 N 份。
- 保留按好友清除、全部清除、恢复备份和保留天数。

### 3.8 设置重组（P1）

设置页改为左侧二级导航、右侧单栏表单：

| 分组 | 内容 |
| --- | --- |
| 数据源与采集 | 演示 / Steam、API Key、暂停与恢复、采样间隔说明 |
| 好友发现 | 自己的资料、定期检查、立即检查 |
| 通知 | 规则列表、全局免打扰与冷却、最近通知 |
| 公开时长 | 时长对比实验总开关、已开启自动采样的账号列表（从时间轴页迁移的入口） |
| 数据与隐私 | 数据概览、保留天数、备份与恢复、自动备份、清除、授权记录 |
| 外观 | 主题、密度、缺口阈值默认值 |
| 关于与更新 | 版本、检查更新、加载本地界面、开机启动、开源许可 |

### 3.9 外观与语言（P2）

- 浅色主题与「跟随系统」；紧凑（36 px 行）与舒适（44 px 行）密度。
- 界面文字抽取到 `ui/lib/strings` 的简体中文表，之后可增加英文。

### 3.10 登录模式验证（P2）

维持计划书安排：用 `sdk-probe` 和授权测试账号对照 Steam 官方好友界面，确认隐身、私密游戏、登录过期等场景的可见范围后，再决定是否作为第二数据源进入发行版。采集接口已在 `collect/` 下独立，新增数据源只需实现同样的观测输出。

## 四、信息架构

```text
侧栏（固定 208 px，窄窗口收为 62 px 图标栏；底部为采集状态、数据来源和刷新）
├─ 好友        开黑面板 · 名单 · 详情 ─→ 横向时间轴（二级页，含时长对比）
├─ 活动        多好友泳道 · 事件面板
├─ 回顾        周报 · 热力图 · 排行 · 按日
└─ 设置        七个分组（二级导航）
全局：首次引导（弹窗）· 提示条（toast）· 演示横幅
```

页面间跳转保持现有行为：切换页面保留筛选、滚动和选中项；从回顾的时段跳到时间轴，再跳到活动页定位事件，都能原路返回。

## 五、UI 设计方案

### 5.1 设计语言

**原则：颜色只属于数据。** 界面本身是单色的，层次靠底色明度区分；彩色只用来表示好友状态和时间轴色带，以及成功、警告、错误反馈。这样屏幕上最显眼的永远是「谁在玩」。所有数值定义在 `src/ui/styles/tokens.css`，其他样式文件不写色值、字号和圆角的字面量。

**表面与文字**

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg-0` | `#0d0f11` | 窗口 |
| `--bg-1` | `#14171a` | 侧栏、面板、弹窗 |
| `--bg-2` | `#1c2024` | 控件、选中行、内嵌区块 |
| `--bg-3` | `#262b30` | 悬停与按下 |
| `--line` / `--line-strong` | 白 7% / 14% | 行间发丝线 / 输入框描边 |
| `--text-1` / `--text-2` / `--text-3` | `#f3f5f6` / `#a4acb3` / `#7d858d` | 主要、次要、辅助文字 |
| `--ink` | `#0d0f11` | 亮色填充上的文字 |

面板不描边、不嵌套：一个面板内部用发丝线和小标签分区，需要内嵌区块时用 `--bg-2`。

**状态色**（文字与圆点 / 时间轴色带）

| 状态 | 文字 | 色带 | 额外区分 |
| --- | --- | --- | --- |
| 游戏中 | `#3ddc97` | `#3ddc97`（带内文字用 `--ink`） | 游戏图标 + 名称 |
| 在线 | `#5aa9ff` | `#2f5f96` | 实心圆点 |
| 离开 | `#f0b64a` | `#8a6a2a` | 文字标签 |
| 忙碌 | `#f2777a` | `#8f4a55` | 文字标签 |
| 显示离线 | `#7d858d` | `#3a4148` | 灰色实心圆点 |
| 状态未知 | `--text-2` | `#565c66` | 空心圆点 |
| 采集缺口 | — | 中性斜纹 `--hatch-a` / `--hatch-b` | 斜纹图案 |
| 无记录 | — | `#171a1d` | 几乎与底色相同 |
| 时长增长 | — | `#e9edf0` | 菱形 |

缺口和无记录表示「没有数据」，所以不占用任何色相。头像一律是中性圆形，避免名字旁出现被误读为状态的颜色。

**字体与尺寸**：界面字体 Segoe UI Variable / 微软雅黑；时间和坐标刻度用等宽数字字体（Cascadia Mono，回退 Consolas），含中文的时长用 `tabular-nums`。字号五级：12（辅助、标签）、13（控件、次要正文）、14（正文）、18（区块标题）、28（页面标题）。字重两级：400 与 600。

**形状与间距**：4 px 基准，常用 4 / 8 / 12 / 16 / 24 / 32。圆角三种：4（标记、小块）、6（控件）、10（面板、弹窗），头像和状态点为圆形。控件高 34 px，紧凑控件 28 px；名单行 56 px。

**控件层级**：主要按钮为浅底深字，每页最多一个；次要按钮为 `--bg-2` 底、无描边；链接为带下划线的文字。少数几项之间的切换用分段控件；筛选和分组跳转用带底线的分页标签。选中状态用更亮的底色和 600 字重表示，不使用彩色。

**外框**：只有侧栏和页面。采集状态、数据来源、刷新和版本在侧栏底部，点状态打开采集详情；没有顶栏和底栏。

**动效**：只用于状态变化提示（名单行变化时 450 ms 底色提示）、定位和弹层出现；系统开启减少动画时全部关闭。

### 5.5 状态设计

| 状态 | 表现 |
| --- | --- |
| 加载中 | 首次加载显示骨架行；刷新时保留旧数据，只在侧栏状态显示「正在采集」 |
| 空 | 图标 + 一句原因 + 一个下一步按钮（例如「还没有添加好友 · 添加自己的账号」） |
| 错误 | 全局错误用 toast（需手动关闭）；表单错误显示在字段下方；单个好友不可见只在该行标注 |
| 采集中断 | 名单行徽标为「采集中断」，游戏前加「上次 ·」，详情显示「上次观测 21:14，当前未更新」 |
| 演示 | 横幅 + 数据源标签「示例数据」；资料链接等真实操作禁用并说明原因 |

### 5.6 可访问性与键盘

- 所有色带、标记有文字等价（`aria-label`、选中详情）；颜色之外用斜纹、空心点、菱形区分。
- 键盘：`Ctrl+K` 搜索；`1–4` 切换主页面（P1）；时间轴聚焦后方向键平移、`+/-` 缩放、`Esc` 清除选中；弹窗打开时焦点锁定，关闭后回到触发按钮。
- 文字对比度 ≥ 4.5:1，焦点环 2 px `--text-1`。
