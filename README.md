# SteamMonitor

Windows 本地工具，用于查看 Steam 好友的可见状态和活动历史。

## 打开应用

有便携版时，打开 `release` 内对应版本文件夹中的 `SteamMonitor.exe`。整个目录一起移动即可。也可以在源码目录执行：

```powershell
npm.cmd ci
npm.cmd start
```

首次启动进入演示模式。点右上角刷新按钮可以模拟下一次采样。在「活动」页试用好友、游戏、日期筛选和 CSV 导出。

## 0.7.4 检查更新

在「设置 → 软件更新」点「检查更新」。应用使用本机 Git for Windows 已保存的 GitHub 登录读取私有仓库的正式发布。兼容界面可以点「立即更新界面」，后台采集继续运行。完整版本通过「打开下载页」下载 Windows ZIP，解压后退出旧版并打开新版。也可以选择本地便携版文件夹加载兼容界面。

发布时将 `package.json` 与锁文件更新到同一版本，提交后推送对应版本标签（例如 `v0.7.4`）。GitHub Actions 会测试并生成界面更新包和 Windows 便携版 ZIP。

## 0.7.2 同期缺口批量删除

在时间轴选中已恢复的缺口，点「删除缺口…」查看同期名单。开始时间、恢复时间和原因一致的缺口归入同批。原因一致且两个时间各相差 10 秒以内的记录可手动追加。可以只删当前一条，也可以删除整批。删除范围涵盖所有好友。

## 0.7.1 缺口合并与单条删除

收起短缺口后，同一游戏的前后区段在时间轴与按日回顾中合并，时长只累计两侧的实际观测。选中已恢复的斜纹缺口，在详情点「删除缺口」可将该条记录从时间轴、事件列表和 CSV 移除。时长统计仍扣除中断时间。要选中自动收起的缺口，可先点「显示全部缺口」。

## 0.7 交互与方图标

切换好友、活动和回顾页面会保留本次打开应用期间的筛选、滚动位置和选中内容。按日回顾中的游戏时段可以打开对应好友时间轴，再定位到活动页事件。右上角的采集状态可查看最近成功观测、最后一次检查、错误和下次尝试时间。

游戏优先显示 Steam 社区的正方形图标。时间轴、列表和选中详情分别使用 16、20 和 32 像素。素材缓存继续保存在本机，系统启用减少动画时会关闭过渡和滚动动画。

## 0.6.5 时间轴时长副行

活动页和好友横向时间轴的色带显示状态或游戏。区段时长在色带下方居中显示，窄段可悬停或点选查看。短缺口两侧状态和游戏相同时，合并色带显示合计观测时长并扣除缺口。时长增长在独立的一行用菱形显示。

## 0.6.4 区段时长和游戏素材

活动页和好友横向时间轴会在色带里显示观测时长。窄段可以悬停或点选查看时长和起止时间。时长按所加载范围内的观测区段计算，收起的短缺口不会计入前后的色带。

游戏封面和商店名称按 App ID 缓存在 `%APPDATA%\SteamMonitor\game-assets.sqlite`。界面优先显示简体中文名称，缺少中文名时使用记录里的游戏名。首次遇到未缓存的游戏需要联网读取素材，已经缓存的名称和封面离线也能显示。

## 0.6.3 短缺口显示

活动页和好友横向时间轴共用「缺口阈值」，默认 3 分钟，可设为 0 至 60 分钟。点「显示全部缺口」或输入 0 可以查看完整缺口。只有已恢复且不超过阈值的缺口才会收起，前后状态与游戏相同的色带会接起来。原始记录、统计和 CSV 导出继续按实际采样处理。

## 0.6.1 时间轴交互

活动页和好友详情都支持 Ctrl + 滚轮缩放。放大后，拖动时间轴、使用横向滚动或点左右按钮可以平移时间窗口。键盘聚焦时间轴后，用方向键平移、加减键缩放、Esc 清除选中项。活动页还可以在概览中拖选范围，或在放大后点概览跳到对应时段。

移动时间范围时会保留选中项。如果选中的时间移出画面，可以用「找回选中项」跳回。回看期间时间窗口保持固定，点「回到最新」恢复跟随采样。

## 0.6 多好友活动时间轴

- 「活动」页默认显示近 24 小时。支持近 6 小时、今天、近 7 天和自定义日期，最多选 31 个日历日。
- 每位好友一条泳道。色带显示采样得到的状态或游戏，斜纹标记采集缺口，菱形标记发现公开游戏时长增长的时间。点色带或标记查看详情，点下方事件可回到对应泳道。
- 从顶部概览拖选时间，或使用缩放按钮和 Ctrl + 滚轮。放大后时间窗口固定，点「回到最新」恢复跟随采样。CSV 导出当前时间窗口的状态和游戏活动记录，时长增长在页面单独查看。

## 0.5 按日回顾和活动图标

在「回顾 → 按日」选日期和好友，可查看当天各游戏的观测时长及每段开始、结束时间。时间按本机时区计算，跨零点按日期拆分，采集缺口单独处理。

「活动」按行显示好友头像和相关游戏图标，切换游戏时同时显示前后的游戏。头像或图标无法加载时保留文字与占位图标。

## 0.4 自动时长采样

在「好友 → 横向时间轴 → 公开游戏时长对比」开启自动采样。每个账号单独确认授权，首次采样建立基线，程序运行时约每 30 分钟检查一次。手动采样仍可使用。

时长增长按发现时间显示在独立的时间轴行。程序按游戏 App ID 区分同期有记录、可能对应近期会话和未匹配到会话，并标出对比期间的采集缺口。这些标记反映可见数据和累计时长差异，无法确认隐身或开玩时间。关闭自动采样会保留已记录的数据。清除历史或恢复备份后需重新启用自动采样。

## 0.3 新功能

- 工作台使用固定侧栏、状态卡片和独立滚动的内容区。状态卡片可以直接筛选名单，好友页按 `Ctrl+K` 聚焦搜索。
- 在「设置 → 好友发现」填写自己的 Steam 资料并启用检查。程序每 30 分钟读取一次公开好友名单，首次列出尚未添加的账号，之后提示新增。你可在好友页查看名单、勾选并确认要记录的人。
- [Steamworks 好友视角验证探针](sdk-probe/README.md) 随源码提供。它需要官方 SDK、获授权的测试 AppID 和已登录的 Steam 客户端。便携版使用公开 Web API。

## 0.2 新功能

- 在「好友」选中一位好友，点详情里的「横向时间轴」。在线状态和游戏分两行显示，支持 6 小时、24 小时、7 天和 30 天。点选时间段可看游戏与起止时间。好友头像和游戏图片来自 Steam，加载失败时用字母或手柄图标显示。
- 点搜索框旁的手柄按钮按游戏分组，点组标题旁的星标置顶。在「回顾」查看 7 天或 30 天的游戏时长和重叠时段。时长按相邻采样估算，采集缺口不计入统计。
- 「设置」可配置上线、开玩、凑人通知，以及免打扰时段和冷却。点「发送测试通知」检查 Windows 是否能显示通知。数据管理支持按保留天数清理、备份、恢复和登录 Windows 后在托盘启动。
- 「横向时间轴」下方有公开游戏时长对比实验。仅手动采样自己的账号或主动请求时长记录的好友，实时模式每个账号至少间隔 10 分钟。可清除样本。累计分钟增加与同期没有观测到该游戏可以同时成立，Steam 延迟同步、采集间隔和资料可见性都会影响结果。

## 接入自己的 Steam 数据

1. 打开「设置」，保存自己的 [Steam Web API Key](https://steamcommunity.com/dev/apikey)，切换到「Steam 数据」。
2. 在好友页添加 SteamID64 或个人资料链接，也可以预览公开好友名单并勾选。选择自己的账号或已请求记录并知悉保存内容的好友。
3. 每约 60 秒采样一次，关闭窗口后仍可在系统托盘查看、暂停或退出。断网、暂停和休眠会留下采集缺口。

状态和历史存于本地应用数据目录 `%APPDATA%\SteamMonitor` 下的 `history.sqlite`。API Key 由 Windows 系统凭据保护，单独保存在 `steam-key.enc`。演示记录独立保存在内存中。活动事件列表可继续加载窗口内的历史。用 Excel 导入时，将 SteamID64 列指定为文本以保留全部位数。

## 本地开发

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:ui
npm.cmd run package:win
```

源码分为 `src/main`（主进程：采集、存储、IPC）、`src/ui`（React 界面：app / pages / components / lib）和 `src/shared`（两端共用的类型与规则）。模块边界和新增 IPC 方法的步骤见 [架构说明](docs/架构说明.md)，功能与界面路线图见 [设计规划](docs/设计规划.md)。早期的 [项目计划书](docs/项目计划书.md) 和 [活动页设计提案](docs/活动页设计提案.md) 也在 `docs` 目录。

打包需要先下载 Electron 运行时，生成的新目录位于 `release`。各版本使用同一份本地数据，切换版本前从托盘退出旧实例。Steam 好友权限下的登录采集仍待验证，需要独立的授权测试账号与 Steam 官方好友界面对照。
